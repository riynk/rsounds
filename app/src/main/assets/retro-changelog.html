RSOUNDS 1.0.1

RSOUNDS release

This page records changes made for RSOUNDS. Older Retro Music release notes are not shown here as RSOUNDS updates.

Identity & appearance

  • Updated the app name and Android application ID for RSOUNDS.
  • Applied the RSOUNDS R and Play logo to the launcher icon and splash screen.
  • Updated the About page with the RSOUNDS maintainer profile and verified project social links.
  • Removed unverified store-rating and upstream donation destinations; shared links now point to RSOUNDS project resources.
  • Aligned the in-app and GitHub bug-report routes with the RSOUNDS issue template and replaced inherited FAQ content.

Now Playing

  • Refined Over Cover lyrics so the album artwork is dimmed beneath the lyrics without an extra fading panel or frame.

RSOUNDS is based on the Retro Music open-source codebase. Earlier upstream release history remains part of that project's history, not this RSOUNDS changelog.
